# G-05: 安全规范

## 输入验证

- 所有用户输入必须校验
- 白名单验证（允许什么），非黑名单（禁止什么）
- 校验长度、类型、格式、范围

## SQL 注入

- 使用参数化查询（Prepared Statements）
- 禁止字符串拼接 SQL
- ORM 自动生成查询

## XSS

- 输出编码（HTML Entity）
- 使用模板自动转义
- Content Security Policy (CSP)

## CSRF

- 使用 CSRF Token
- SameSite Cookie 属性
- 验证 Referer/Origin

## 认证与会话

- JWT: 短期有效（≤24h），使用 HTTPS
- 密码: bcrypt/argon2 加密，禁止明文存储
- Cookie: HttpOnly, Secure, SameSite 属性
- 会话 ID 随机生成，登录后重新生成
- 会话超时: 空闲 30 分钟，绝对 24 小时
- 注销时销毁会话

## 密钥管理

- 禁止硬编码密钥、密码、Token
- 使用环境变量或密钥管理服务
- `.env` 文件禁止提交 Git

## 敏感数据

- 日志禁止输出: 密码、Token、完整手机号、身份证号
- API 响应脱敏: 手机号 `138****8888`
- 数据库加密: 敏感字段（身份证、银行卡）

## 权限

- 最小权限原则
- 水平越权检查（只能访问自己的数据）
- 垂直越权检查（角色权限）

## 文件上传

- 限制文件类型（白名单）
- 限制文件大小
- 存储到非 Web 目录，禁止执行权限
- 重命名文件（防止覆盖）

## 限流

- API 限流: 按 IP/用户限流
- 登录限流: 失败次数锁定
- 返回 429 (Too Many Requests)

## CORS

- 只允许特定域名访问
- 禁止 `Access-Control-Allow-Origin: *`
- 敏感接口禁用 CORS

## 安全头部

```
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
X-XSS-Protection: 1; mode=block
Strict-Transport-Security: max-age=31536000
Content-Security-Policy: default-src 'self'
```

## 依赖安全管理

- 定期运行安全扫描（`npm audit`, `govulncheck`）
- 不使用已知漏洞的依赖版本
- 固定依赖版本，避免自动更新引入漏洞
- 最小化依赖数量，减少攻击面
- 订阅安全公告

## 错误处理安全

- 生产环境返回通用错误消息，不暴露堆栈/数据库/路径
- 详细错误仅记录到服务端日志
- 全局错误处理器实现详见 G-10
