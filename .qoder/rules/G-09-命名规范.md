# G-09: 命名规范

## 通用原则

1. **见名知意**：命名应清晰表达用途，避免缩写（除非是通用缩写如 ID、URL）
2. **一致性**：同一项目中保持命名风格一致
3. **避免歧义**：不用 data、info、tmp 等模糊命名

## Go 命名

### 变量

```go
// 正确
currentUser := getCurrentUser()
maxRetryCount := 3
isActive := true

// 错误
u := getCurrentUser()  // 太简短
data := fetchData()    // 太模糊
flag := true           // 无意义
```

### 函数

```go
// 正确 - 动词开头
func GetUserByID(id uint) (*User, error)
func CreateUser(req CreateUserRequest) (*User, error)
func ValidateEmail(email string) error
func CalculateTotalPrice(items []Item) decimal.Decimal

// 错误
func User(id uint)          // 缺少动词
func Handler(c *gin.Context) // 太泛化
func DoSomething()          // 无意义
```

### 结构体

```go
// 正确 - 名词，首字母大写表示可导出
type User struct {
    ID         uint
    Username   string
    CreateTime time.Time
}

type UserRepository struct {
    db *gorm.DB
}

type CreateUserRequest struct {
    Username string
    Email    string
}

// 错误
type user struct{}           // 私有但应该导出
type Data struct{}           // 太泛化
type T struct{}              // 无意义
```

### 接口

```go
// 正确 - 动词+er 或 名词+接口
type UserRepository interface {
    GetByID(id uint) (*User, error)
    Create(user *User) error
}

type Validator interface {
    Validate() error
}

// 错误
type IUser interface{}       // 不需要 I 前缀
type Repo interface{}        // 太简短
```

### 常量

```go
// 正确
const MaxRetryCount = 3
const DefaultPageSize = 20
const JWTExpireHours = 24

const (
    UserStatusActive   = 1
    UserStatusInactive = 0
)

// 错误
const max = 3               // 太简短
const DEFAULT = 20          // 无意义
```

### 错误变量

```go
// 正确
var ErrUserNotFound = errors.New("user not found")
var ErrInvalidCredentials = errors.New("invalid credentials")

// 错误
var NotFound = errors.New("not found")  // 太泛化
```

## Vue/TypeScript 命名

### 组件

```vue
<!-- 正确 - PascalCase -->
<UserCard />
<CampaignList />
<CreateCampaignForm />

<!-- 错误 -->
<user-card />
<!-- kebab-case 不推荐 -->
<card />
<!-- 太泛化 -->
<component1 />
<!-- 无意义 -->
```

### 组件文件

```
// 正确 - PascalCase
UserCard.vue
CampaignList.vue
CreateCampaignForm.vue

// 错误
user-card.vue           // kebab-case
card.vue                // 太泛化
component1.vue          // 无意义
```

### 变量

```typescript
// 正确 - camelCase
const currentUser = ref<User | null>(null);
const isLoading = ref(false);
const campaignList = computed(() => store.campaigns);

// 错误
const CurrentUser = ref(); // PascalCase 用于组件/类
const current_user = ref(); // snake_case 用于 Go/Python
const x = ref(); // 无意义
```

### 函数

```typescript
// 正确 - 动词开头，camelCase
function fetchUserById(id: string): Promise<User>;
function validateForm(): boolean;
function handleSubmit(): void;
function formatCurrency(amount: number): string;

// 错误
function user(); // 名词，缺少动词
function getData(); // 太泛化
function doSomething(); // 无意义
```

### 类型/接口

```typescript
// 正确 - PascalCase
interface User {
  id: string;
  name: string;
}

interface CreateUserRequest {
  name: string;
  email: string;
}

type UserStatus = "active" | "inactive";

// 错误
interface user {} // 小写
interface IUser {} // 不需要 I 前缀
interface Data {} // 太泛化
```

### Composables

```typescript
// 正确 - use + 名词，camelCase
useUser.ts;
useCampaign.ts;
useLocalStorage.ts;

// 错误
user.ts; // 缺少 use 前缀
UseUser.ts; // 首字母大写
use - user.ts; // kebab-case
```

## 数据库命名

### 表名

```sql
-- 正确 - snake_case，复数
users
campaigns
ad_accounts
user_roles

-- 错误
user                          -- 单数
Campaigns                     -- 大写
adAccounts                    -- camelCase
tbl_users                     -- 前缀冗余
```

### 字段名

```sql
-- 正确 - snake_case
id
user_id
create_time
update_time
is_deleted

-- 错误
userId                        -- camelCase
CreatedAt                     -- 大写
createdAt                     -- camelCase
```

### 索引名

```sql
-- 正确
idx_user_id
idx_status_create_time
uk_email                        -- unique key

-- 错误
index_user_id                 -- 太长
user_id_idx                   -- 顺序不一致
```

## API 命名

### 路由

```
// 正确 - kebab-case，复数名词
GET    /api/v1/users
GET    /api/v1/users/:id
POST   /api/v1/users
PUT    /api/v1/users/:id
DELETE /api/v1/users/:id

GET    /api/v1/campaigns
GET    /api/v1/campaigns/:id/stats

// 错误
GET    /api/v1/getUsers         // 动词，RESTful 不需要
GET    /api/v1/user             // 单数
GET    /api/v1/UserList         // 大写
```

### 查询参数

```
// 正确 - snake_case（保持一致）
?page=1&page_size=20
?sort_by=create_time&order=desc
?status=active&user_id=123

// 错误
?Page=1                         // 大写
?pageSize=20                    // camelCase（如果其他用 snake_case）
```

## 常见命名对照表

| 概念     | Go              | TypeScript/Vue   | 数据库      |
| -------- | --------------- | ---------------- | ----------- |
| 用户ID   | userID / UserID | userId           | user_id     |
| 创建时间 | CreateTime      | createTime       | create_time |
| 更新时间 | UpdateTime      | updateTime       | update_time |
| 是否删除 | IsDeleted       | isDeleted        | is_deleted  |
| 获取用户 | GetUserByID     | fetchUserById    | -           |
| 用户列表 | users           | userList / users | users       |
| 状态码   | StatusCode      | statusCode       | status_code |

## 禁止的命名

### 模糊命名

```
// 禁止
data, info, tmp, temp, obj, item, val, value
flag, status, count, num, number, str, string
```

### 单字母命名（除特定场景）

```go
// 允许（循环/闭包）
for i := 0; i < 10; i++ {}
users.map(u => u.name)

// 禁止
func GetUser(u string) {}     // u 是什么？
```

### 拼音/缩写

```
// 禁止
yonghu                          // 拼音
yh                              // 缩写
userInfo -> uInfo               // 无意义缩写
```

## 命名检查清单

```
□ 命名是否清晰表达了用途？
□ 是否遵循了项目约定的大小写规范？
□ 是否避免了模糊命名（data/info/tmp）？
□ 是否避免了无意义缩写？
□ 同一概念在不同地方命名是否一致？
□ 函数是否以动词开头？
□ 布尔值是否以 is/has/should 开头？
```
