# G-08: 部署规范

## 本地开发部署

### 环境要求

- Go 1.21+
- Node.js 18+
- MySQL 8.0+
- Redis 7.0+ (可选)

### 后端部署

```bash
# 1. 进入后端目录
cd backend

# 2. 安装依赖
go mod download

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 填写数据库连接等信息

# 4. 运行数据库迁移
make migrate-up

# 5. 编译
go build -o server ./cmd/server

# 6. 启动服务
./server
# 或使用 air 热重载
air
```

### 前端部署

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填写 API 地址

# 4. 启动开发服务器
npm run dev

# 5. 构建生产版本
npm run build
```

## 环境变量配置

### 后端 (.env)

```bash
# 服务配置
SERVER_PORT=8080
SERVER_MODE=development

# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=your_database

# JWT 配置
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRE_HOURS=24

# 日志配置
LOG_LEVEL=info
LOG_FORMAT=json
```

### 前端 (.env.local)

```bash
# API 地址
VITE_API_BASE_URL=http://localhost:8080/api/v1

# 其他配置
VITE_APP_TITLE=YourApp
```

## 数据库迁移

### 迁移文件命名

`{序号}_{动作}_{表名}.sql`

示例：

- `001_create_users.sql`
- `002_add_user_status.sql`

### 迁移文件格式

```sql
-- UP
CREATE TABLE users (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- DOWN
DROP TABLE IF EXISTS users;
```

### 迁移命令

```bash
# 执行所有待执行迁移
make migrate-up

# 回滚最近一次迁移
make migrate-down

# 查看迁移状态
make migrate-status

# 创建新迁移文件
make migrate-create NAME=add_campaign_table
```

## 日志查看

### 后端日志

```bash
# 开发模式（终端输出）
./server

# 生产模式（文件输出）
./server > /var/log/app/app.log 2>&1

# 查看实时日志
tail -f /var/log/app/app.log

# 查看错误日志
grep "ERROR" /var/log/app/app.log
```

### 前端日志

```bash
# 浏览器开发者工具 Console 面板
# 或
npm run dev  # 终端输出构建日志
```

## 常见问题排查

### 后端启动失败

```bash
# 检查端口占用
lsof -i :8080

# 检查数据库连接
mysql -u root -p -e "SELECT 1"

# 检查环境变量
cat .env

# 查看详细错误
./server 2>&1 | tee startup.log
```

### 前端构建失败

```bash
# 清除缓存
rm -rf node_modules
rm package-lock.json
npm install

# 检查类型错误
npx vue-tsc --noEmit

# 检查依赖冲突
npm ls
```

### 数据库连接失败

```bash
# 检查 MySQL 服务
systemctl status mysql

# 检查连接配置
mysql -h localhost -P 3306 -u root -p

# 检查数据库是否存在
SHOW DATABASES LIKE 'your_database';
```

## 热重载开发

### 后端热重载

使用 `air` 工具：

```bash
# 安装 air
go install github.com/cosmtrek/air@latest

# 启动热重载（配置见项目 .air.toml）
air
```

### 前端热重载

```bash
npm run dev
```

Vite 默认支持热模块替换（HMR）。
