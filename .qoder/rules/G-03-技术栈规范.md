### 组件拆分

**按业务模块组织文件，不要机械拆分：**

- ✅ 一个完整业务模块（如订单详情、排期管理）可以 400-500 行放在一个文件
- ✅ 跨模块复用时才拆分提取（如通用表单组件、通用列表）
- ❌ 不要因为"行数多了"就把一个模块拆成 5-6 个小文件
- ❌ 不要为了一个按钮/一个小功能创建独立组件

**必须拆分的场景：**

- 组件被 2 处以上页面复用 → 提取为公共组件
- 包含 3 个以上独立业务模块 → 按模块拆分
- 单文件 > 800 行且难以维护 → 考虑拆分

### Pinia Store

```ts
export const useUserStore = defineStore("user", () => {
  const user = ref<User | null>(null);
  const isLogin = computed(() => !!user.value);
  const login = async (data: LoginData) => {
    user.value = await api.login(data);
  };
  return { user, isLogin, login };
});
```

### 查询与事务

```go
func (r *UserRepo) List(ctx context.Context, req ListRequest) ([]User, int64, error) {
    var users []User; var total int64
    query := r.db.WithContext(ctx).Model(&User{}).Where("is_deleted = 0")
    if req.Status > 0 { query = query.Where("status = ?", req.Status) }
    query.Count(&total)
    err := query.Order("create_time DESC").Offset((req.Page-1)*req.Size).Limit(req.Size).Find(&users).Error
    return users, total, err
}

err := r.db.Transaction(func(tx *gorm.DB) error {
    if err := tx.Create(&order).Error; err != nil { return err }
    if err := tx.Update("stock", gorm.Expr("stock - ?", qty)).Error; err != nil { return err }
    return nil
})
```

```go
func (s *Service) GetUser(id uint) (*User, error) {
    user, err := s.repo.Get(id)
    if err != nil {
        if errors.Is(err, gorm.ErrRecordNotFound) { return nil, NewError(CodeResourceNotFound, "用户不存在") }

    }
    return user, nil
```

索引：`UserID uint gorm:"index"`, `Status int gorm:"index"`

## 数据库

### 表设计

```sql
CREATE TABLE {table_name} (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT UNSIGNED NOT NULL,
    name VARCHAR(100) NOT NULL,
    status TINYINT NOT NULL DEFAULT 1,
    is_deleted TINYINT(1) NOT NULL DEFAULT 0,
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id), INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 字段类型

| 类型            | 场景       |
| --------------- | ---------- |
| BIGINT UNSIGNED | 主键、外键 |
| VARCHAR(n)      | 字符串     |
| TEXT            | 长文本     |
| DECIMAL(10,2)   | 金额       |
| TINYINT         | 状态、布尔 |
| DATETIME        | 时间       |
| JSON            | 灵活结构   |

### 禁止

- FLOAT/DOUBLE 存金额
- 外键约束（应用层控制）
- 触发器、存储过程
- 单表 > 40 个字段 / > 8 个索引

### 迁移文件

命名：`{序号}_{动作}_{表名}.sql`

```sql
-- UP: CREATE TABLE users (id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT, name VARCHAR(100) NOT NULL);
-- DOWN: DROP TABLE IF EXISTS users;
```

原则：只写 DDL，必须可逆，幂等执行。

### 数据兼容

新增字段：`ALTER TABLE users ADD COLUMN status TINYINT NOT NULL DEFAULT 1;`

删除字段（标记废弃）：`ALTER TABLE users ADD COLUMN age_deprecated TINYINT DEFAULT 0;`

### 关联设计

| 类型   | 实现            |
| ------ | --------------- |
| 一对一 | 外键 + 唯一索引 |
| 一对多 | 外键            |
| 多对多 | 中间表          |

中间表：`user_roles` 含 `user_id`, `role_id`, `UNIQUE KEY uk_user_role (user_id, role_id)`

### 查询优化

索引设计：外键必加索引，查询条件加索引。

慢查询：`EXPLAIN SELECT * FROM orders WHERE user_id = 1;`

优化方向：加索引、减少 SELECT \*、分页查询。

## Redis

### Key 命名

```
user:{id}:profile
cache:campaign:{id}:stats
session:{token}
lock:resource:{type}:{id}
```

冒号分隔，业务前缀在前。禁止无前缀裸 key。

### 缓存模式

```
读：先查 Redis → 命中返回 → 未命中查 DB → 写 Redis → 返回
写：先写 DB → 删除/更新 Redis 缓存
```

### 连接池

```python
import redis
r = redis.Redis(connection_pool=redis.ConnectionPool(
    max_connections=20,
    decode_responses=True,
))
```

### 禁止

- key 用中文或空格
- 无过期时间的缓存（内存泄漏）
- 大 key（单 key > 10MB）
- KEYS \* 命令（生产用 SCAN）
