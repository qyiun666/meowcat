## 四、Slot-Plug-Extension 机制

```
Slot（插槽）= Protocol + OrganSpec
  框架定义接口约束。20 个 Protocol（@runtime_checkable），每个 OrganSpec 定义
  in_edges/out_edges/read/write_methods/supported_styles。

Plug（插头）= AgentOrgan / SkillOrgan 适配器
  应用层提供。包装外部实现，_delegate("method", **kw) 自动 sync/async + 错误包装。

Extension（扩展）= Pluggable hook
  挂在方法上的插件函数，按注册顺序执行，3 种模式：
  · First-hit：第一个非 None → 短路
  · Merge：全部合并到默认值
  · Replace：第一个替代默认
  扩展先于默认逻辑执行。
```

## 六、脑内 Wiring 全图

> 约束：大脑不产生副作用。cerebrum 禁止直连 paws/mouth/growth organs。
> 所有副作用走 cerebrum → cerebellum → effectors 漏斗。

```
sensors（ears/eyes/whiskers）
     ↓
  thalamus ──→ cerebrum ──→ cerebellum ──→ effectors（paws/mouth/purr/tail）
     ↓              ↑            ↑
     ├──→ amygdala  │            │
     ↓              │            │
  brainstem ────────┘ ──────────┘
     ↓
  hypothalamus → hippocampus → cortex
     ↑              ↓
  growth organs ←───┘
```

## 八、LLM 调用机制与格式缺口

### 8.1 当前流程

```
用户消息 → Ears → Thalamus（路由决策）
                      ↓
               Brainstem.build_system_prompt(organ, route, cat_self_snapshot)
                      │  7步装配链：
                      │  1. 插件链覆写
                      │  2. PromptPreset.pre_prompt
                      │  3. OrganPrompt.identity + perspective
                      │  4. 路由模板（4层回退优先级）
                      │  5. CatSelf 注入（性格+信念+能力）
                      │  6. OrganPrompt.output_format
                      │  7. PromptPreset.post_prompt
                      ↓
                   系统提示词 字符串
                      ↓
               Cerebrum.generate(prompt=str, system_prompt=str) → str
                      ↑
               应用层自己组装成 OpenAI messages 数组，调用真实 LLM API
```

### 8.2 各器官 LLM 调用输入一览

| 器官       | 是否调 LLM | 输入参数                                                   | 返回   |
| ---------- | :--------: | ---------------------------------------------------------- | ------ |
| cerebrum   |     是     | `generate(prompt, system_prompt, temperature, max_tokens)` | `str`  |
| cerebellum |     是     | 同上                                                       | `str`  |
| amygdala   |    可能    | `assess_safety(input)`                                     | `dict` |
| frontal    |    可能    | 任务拆解                                                   | —      |
| cortex     |    可能    | 蒸馏                                                       | —      |

### 8.3 格式缺口 — 没有统一容器

当前框架层只传**裸字符串**。缺少一个标准化的上下文对象包装：

**缺的输入容器 (UnifiedContext)：**

```
┌─ UnifiedLLMContext ──────────────────────┐
│  system_prompt   — Brainstem 构建的角色   │
│  messages        — 对话历史 [{role, content}]  │
│  tools           — 可用工具（OpenAI func call）  │
│  memories        — 相关记忆片段           │
│  cat_self        — 自我认知快照            │
│  route           — 路由类型（chat/tool）   │
│  budget          — token 预算约束          │
└──────────────────────────────────────────┘
```

**缺的输出容器 (UnifiedResponse)：**

```
┌─ UnifiedLLMResponse ─────────────────────┐
│  content        — 文本内容                │
│  tool_calls     — 工具调用请求             │
│  finish_reason  — stop/tool_calls/length │
│  usage          — token 用量              │
└──────────────────────────────────────────┘
```

**影响范围**：如果加上这个统一容器，cerebrum/cerebellum/amygdala/frontal/cortex 所有需要 LLM 的器官都用同一套输入输出格式，应用层不需要每个器官单独适配。

## 十一、复杂度评估

### 客观数字

| 维度            |      meowcat      |  meowagent   | MeowDesk |
| --------------- | :---------------: | :----------: | :------: |
| 源文件          |        154        |     141      |    35    |
| 器官数量        |        20         | 20（全实现） |    —     |
| Protocol        |        20+        |      —       |    —     |
| Wiring 边       | 53+ 合法 / 6 禁止 |      —       |    —     |
| Path/Chain/Loop |      31/8/7       |      —       |    —     |
| React 组件      |         —         |      —       |    20    |
| Zustand Store   |         —         |      —       |    7     |

### 正合适

- 20 器官分类直观，meowagent 全量实现证明设计有效
- Protocol + OrganSpec 单点真相
- 禁止边（cerebrum 不直连 paws）工程上关键
- Path→Chain→Loop 层层组合自然

### 可瘦身（冗余）

- Noop + Renovated 两套默认实现（40 类），功能重叠
- AgentOrgan ≡ SkillOrgan 机制相同，仅语义标签不同
- 4 ImplementationStyle vs 2 Adapter 类型不对齐
- Path/Chain 对外暴露，应用层 90% 只用 Loop

### 关键缺口

- **LLM 调用格式未统一** — 缺少 UnifiedLLMContext / UnifiedLLMResponse 标准化容器。所有调 LLM 的器官目前用裸字符串传递，应用层需要每个器官单独适配 OpenAI 格式。Brainstem 已有 7 步装配链，天然的统一点。
