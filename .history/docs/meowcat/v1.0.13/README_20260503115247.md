# v1.0.13 — Signal Middleware（信号中间件）

> 创建日期: 2026-05-03 | 基版本: v1.0.12

## 定位

`signal()` 是框架最核心的原语。Middleware 在 signal 执行前后提供非侵入拦截点，用于日志、追踪、限流、超时等横切关注点。
